ESP32 Serial Game Controller Adapter Firmware Flasher

This firmware is aimed at making it easier to use a controller with a Cheap Yellow Display (CYD). This firmware is for a supplementary EPS32 board that sends controller input to the CYD on the Serial1 port. Using a supplementary board makes it easier to wire different controllers or use a bluetooth controller. See the Anemoia-ESP32 project for more info on running a NES emulator on a CYD.

Your browser does not support the Web Serial API. Use Chrome or Edge.



As an alternative to the Serial Game Controller Adapter, you can use the Web Serial Controller web page to send control inputs from your PC to the ESP32 NES emulator over the USB to Serial (Serial0) connection. Neither an additional board nor wiring is required!
